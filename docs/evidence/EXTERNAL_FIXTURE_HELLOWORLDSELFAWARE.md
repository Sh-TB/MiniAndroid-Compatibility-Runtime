## What the app does (runtime contract)

`MainActivity extends android.app.Activity implements View.OnLongClickListener`:

1. `setContentView(R.layout.activity_main)` — root view is a **single TextView**,
   `match_parent × match_parent`, `gravity=center`, `fontFamily=monospace`,
   `elegantTextHeight=true`, `lineSpacingMultiplier=2`,
   `textAppearance=@android:style/TextAppearance.Large`,
   `textColor=@color/hello_color` (#FFFFFF).
2. `findViewById(R.id.hello_world_text_View)`.
3. `setText(getString(R.string.hello_message, AndroidInfo.getId(this),
   AndroidInfo.getVersion(), AndroidInfo.getLevel()))` — **ARSC string with
   positional format args**: `hello world\ni'm %1$s\na version %2$s android\nwith
   api level %3$d`.
4. `AndroidInfo` requires: `Settings.Secure.getString(getContentResolver(),
   ANDROID_ID)` (SDK≥26 branch), `Build.VERSION.RELEASE`, `Build.VERSION.SDK_INT`.
5. `setOnLongClickListener(this)` (interaction gate target for GOLDEN-02).

Theme: `AppTheme` parent `android:Theme` (classic platform theme, **not**
AppCompat/Material) with `android:windowBackground=@color/colorPrimary` (#000000).

**Expected visual**: pure black background; centered white monospace text in
4 lines (`hello world` / `i'm <ANDROID_ID>` / `a version <RELEASE> android` /
`with api level <SDK_INT>`).
