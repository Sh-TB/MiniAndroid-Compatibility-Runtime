## 0. The chain (§21 of the campaign brief)

```text
APK
 ↓  apk_parser / manifest_reader           (src/apk/)
 ↓  DEX  dex_parser / class_resolver       (src/dex/)
 ↓  Class  class_resolver + heap objects   (src/dex/, dalvik_engine.cpp)
 ↓  Method  batch interpreter              (dex_interpreter_batch.cpp)
 ↓  Instruction/Invoke  dispatch           (dalvik_engine.cpp bridge_to_api)
 ↓  Android API  shadow registry           (framework/shadow_registry.h, 21+ shadows)
 ↓  Framework state  heap + shadow state   (ViewShadow nodes, ActivityShadow, …)
 ↓  View  ViewNode tree                    (android_shadows.cpp)
 ↓  Layout  measure / layout               (layout_inflater.cpp + shadow measure)
 ↓  Canvas  record + replay                (canvas_shadow.cpp)
 ↓  Framebuffer  software_renderer         (renderer/software_renderer.cpp)
 ↓  PNG/PPM  PNGWriter + TextShaper        (software_renderer, fonts/)
 ↓  Pixel evidence  PIL + view_tree.json   (tools/verify, tools/architecture)
```

Each hop's live/dead verdict comes from `S68_BUILD_GRAPH.json` (40 live TUs,
27 dead — dead code is never fixed or graphed).
