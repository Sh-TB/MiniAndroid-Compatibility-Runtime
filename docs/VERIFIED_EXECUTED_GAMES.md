## Evidence levels (E0–E6)

| Level | Meaning |
|---|---|
| E0 | hypothesis |
| E1 | source evidence |
| E2 | unit test |
| E3 | runtime trace (frames/logs, no meaningful visual) |
| E4 | real APK execution (screenshot/session evidence) |
| E5 | deterministic repeated execution (recorded protocol) |
| E6 | corpus fan-out across APKs (law-level record) |

**Strict status vocabulary:** `VERIFIED / TESTED / OBSERVED / PARTIAL / FAILED / BLOCKED / PENDING`.
A screenshot file alone, an exit code, or an `OBSERVED` status is **never** execution proof.
A game is `VERIFIED` only when repo-recorded runtime evidence supports the execution
semantics (launched → real frames → interaction → state change where claimed).
