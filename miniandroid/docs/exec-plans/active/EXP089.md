## This Round's Progress

### F5 CRITICAL FIX: return-wide + move-result-wide + move-wide

**Root cause:** Three wide-value opcodes were missing or broken:
1. `RETURN_WIDE` (0x10) — MISSING from dispatcher
2. `MOVE_RESULT_WIDE` (0x0B) — hardcoded to `make_int(0)`, discarding wide values
3. `MOVE_WIDE` (0x04) — MISSING from dispatcher

**Impact:** ALL wide values (long, double) were silently lost. This affected:
- System.currentTimeMillis()
- SystemClock.elapsedRealtime()
- File.length()
- Database long values
- Double arithmetic
- Coordinates (lat/long)
- Durations/timeouts

**Fixes:**
- Added `case Opcode::RETURN_WIDE` → `execute_return_wide()`
- Fixed `move-result-wide` to propagate `last_invoke_return_`
- Added `case Opcode::MOVE_WIDE` with 12x format handling
- Added `execute_return_wide()` implementation (reads wide register, stores in last_invoke_return_)

**Regression test:** `tests/exp088_f5_return_wide_test.cpp` (5/5 PASS)
