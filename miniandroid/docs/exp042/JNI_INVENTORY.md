1. APK opened as ZIP, each `classesN.dex` read into memory.
2. DEX header parsed at offset 0 (112 bytes, little-endian).
3. `string_ids[]`, `type_ids[]`, `proto_ids[]`, `method_ids[]` and `class_defs[]` sections loaded.
4. For each `class_def_item`, `class_data_off` resolved and the ULEB128-encoded `class_data_item` parsed.
5. Both `direct_methods[]` and `virtual_methods[]` lists walked. For each `encoded_method`, `access_flags & 0x100` decides if the method is native.
6. Native methods are resolved back to (class, name, shorty) via `method_ids[]` -> `proto_ids[]` -> `string_ids[]`.
7. Library attribution and priority bucket are heuristic, based on the declaring-class descriptor (see the python source for the exact keyword tables).
