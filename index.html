What is MiniAndroid?

An Android compatibility runtime that executes real, unmodified Android APKs (DEX bytecode interpretation + a from-scratch rendering/input stack) outside the Android OS, with an evidence-first engineering process: every fix must carry REPRODUCE → ROOT CAUSE → UPSTREAM LAW → IMPLEMENTATION → TEST → REAL EXECUTION → OBSERVATION → REGRESSION. This wave (S79) proved the full gameplay loop of Snake end-to-end on the runtime.
