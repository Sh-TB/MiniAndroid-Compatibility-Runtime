    Frequently asked questions
    I can't install the app.
    • Unknown sources not enabled: Allow installation from unknown sources for your browser or the official Uptodown app (depending on where you're downloading) in Settings > Apps. For more details, visit our Help Center.
    • Minimum Android version not supported: Make sure your device meets the minimum Android version listed under Requirements on the download page. Also, check compatibility with the file's architecture under Architecture in the app info.
    • Not enough storage space: Free up space by removing apps or files you don't need. If downloaded via a browser, the APK/XAPK file remains on your device, so you'll need at least twice the installer's file size in free space.
    • Corrupt or incomplete file: If your connection is unstable or slow, the file may not download completely. If the installation fails, try downloading it again.
    • Version conflict: If you already have the app installed from another source with a different signature, uninstall it before installing from Uptodown.
    • Installer permissions: Ensure the app you're using to install (browser, file manager, or Uptodown App Store) has permission to install apps.
    The app installs but doesn't work.
    • Minimum requirements not met: Sometimes apps install even if requirements aren't met, but they may not function properly. Verify that your device meets the RAM, processor, and Android version requirements listed in the technical sheet on Uptodown.
    • Discontinued app: Some apps remain available on Uptodown even if their developers no longer maintain them. Apps with online features may not work. Check the publish date of the latest file or visit the developer's official page.
    • Architecture incompatibility: Some apps require specific architectures (e.g., ARM, ARM64, x86). Check under Older versions to see if one is compatible with your device.
    • Corrupt data or cache: If locally saved app data causes issues, go to Settings > Apps, select the app, and clear cache and data. Back up any important information first.
    • Outdated version: If you installed an older version, the app may require an update. Check Uptodown to confirm you have the latest release.
