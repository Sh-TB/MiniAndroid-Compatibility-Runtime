# 21. VALIDATED AGENT FINDING #11 — APUT / ARRAY BOUNDS SEMANTICS

Another previous agent discovery was independently validated against AOSP.

The old MiniAndroid behavior of `aput`:

* silently accepted out-of-bounds writes
* could auto-grow arrays
* could skip null behavior incorrectly

was wrong.

The correct AOSP-like behavior is:

```text
null array → NullPointerException
invalid index → ArrayIndexOutOfBoundsException
valid index → store
```

and:

```text
array length never changes
```

The main coder also completed the related `fill-array-data` semantics.

Preserve these validated fixes.

# 46. DISCRIMINATING TESTS

Every important test should fail on the known-bad implementation where feasible.

Examples:

```text
incorrect array bounds → fixture must fail old engine
missing multi-dex lookup → fixture must fail old resolver
broken MeasureSpec → fixture must produce wrong geometry
wrong font metrics → pixel/layout assertion must fail
missing resource resolution → resource ID assertion must fail
```

Avoid tests that merely exercise code without proving semantics.
